PROJECT RELEASE / 20 AUG 2026

RoboHermes: verified robot experience as inspectable code.

RoboHermes separates visible reasoning from execution authority. A Planner proposes a task strategy, an Engineer composes camera-grounded tools, and a Reviewer diagnoses the visible trace. Candidate code enters an isolated overlay and is retained only after a native simulator-success harness verdict.

FINAL / Adaptive Pass@2

Verified experience recovers failures across the complete perturbation panel.

The fixed arm receives one attempt per identity. Adaptive releases retry only selected fixed failures with reviewed code-backed changes. No task checker, completion latch, checkpoint, policy, object pose, or hidden predicate is visible to the Agent.
